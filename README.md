# 💼 Uday Kiran's CLI Portfolio

> Interactive terminal portfolio - because resumes are boring!

## 🚀 Try it now

```bash
npx udaykiran
```

## 📦 Install Globally (Optional)

```bash
npm install -g udaykiran
udaykiran
```

## 🛠️ Tech Stack

Built with Node.js, TypeScript, and these awesome libraries:

- [Inquirer](https://github.com/SBoudrias/Inquirer.js) - Interactive prompts
- [Chalk](https://github.com/chalk/chalk) - Terminal colors
- [Boxen](https://github.com/sindresorhus/boxen) - Beautiful boxes
- [Ora](https://github.com/sindresorhus/ora) - Elegant spinners

## 🔧 Development

```bash
# Clone the repo
git clone https://github.com/udaykirancodes/npx-udaykiran.git
cd npx-udaykiran

# Install dependencies
npm install

# Run in dev mode
npm run dev

# Build
npm run build
```

## 📝 Customize

1. Fork this repo
2. Update `data.ts` with your information
3. Adjust colors in `ui.ts` if needed
4. Build and publish: `npm run build && npm publish`
